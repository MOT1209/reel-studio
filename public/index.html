    سكريبتات مرجعية (references/examples)

    حط 4–5 سكريبتات من بتوعك، وكل سكريبت جديد هيطلع بنفس النبرة والإيقاع.

      الصوت كله بيتظبط على −14 LUFS في الآخر.

      الموافقات الافتراضية لأي مشروع جديد. «موافقتي» = المرحلة تقف وتستنى تراجعها وتعدّلها.

      إزاي تجيب Client ID و Client secret (مرة واحدة، حوالي 5 دقايق)
      1. افتح Google Cloud Console واعمل مشروع جديد (أي اسم).
      2. فعّل YouTube Data API v3 ← Enable.
      3. OAuth consent screen: نوع External، واكتب اسم التطبيق وإيميلك، وفي Audience ← Test users ضيف الإيميل اللي عليه القناة.
      4. Clients ← Create client ← النوع Desktop app ← Create.
      5. انسخ Client ID و Client secret هنا، ودوس «حفظ واربط القناة».

      ⚠ جوجل بيخلّي أي فيديو بيترفع من مشروع API مش متراجع (unverified) Private لحد ما المشروع يعدّي مراجعة YouTube API audit. عشان تنشر Public أو Unlisted على طول، قدّم على المراجعة من الفورم ده، أو غيّر الخصوصية بإيدك من YouTube Studio. الحصة اليومية حوالي 6 فيديوهات لكل مشروع.
